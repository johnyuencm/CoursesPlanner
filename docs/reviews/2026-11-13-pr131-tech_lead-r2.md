## New items

### N1 (low): the fallback names can still collide across programs

- `titleName()` clips both Map-tier fallback names, `Northeastern Computer Science, MSCS (Boston)` and `Northeastern Computer Science, MSCS—Align (Boston)`, to `Northeastern Computer…`.
- Both programs have courses with the same codes, so 2 sitemap titles can be the same. The new test checks uniqueness only inside one program name.
- This happens only when a published program has no short name. `tests/sitemap-metadata.test.ts` then fails (missing short name, and duplicate titles). Thus CI catches it.
- `docs/ia.md` says the titles "stay unique" in this case. That is true in one program only.

### N2 (low): the documented way to add a name needs a re-crawl

- `docs/add-courseleaf-college.md` step 5 says: set the status to `queued`, then crawl again. That sends network requests for a change to one field.
- This is safe and correct. It also keeps the roadmap file and the config the same. It is a process cost, not a defect.
