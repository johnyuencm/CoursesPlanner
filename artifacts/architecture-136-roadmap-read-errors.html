3. missing-programs answers 503, not 404

Speculative in-process not built: keep 404

Files: lib/roadmap-reader.ts:24, lib/snapshot-assets.ts:58, components/roadmap-selector.tsx:193, :214, :238. Source: TL low 1.

Dev: a local file is lost

The data is broken. 503 would fit.

Production: a crawlable university with no published list

snapshotAsset gives undefined for a file outside the manifest. The same kind fires. "No roadmap here" is true, so 404 fits.

Idea: A lost file is a server state. 503 tells the client that its request is not at fault.

Why not:

  • In production, a 503 would count as a server fault and invite retries.
  • The selector reads only response.ok and error. No reader gains from a new status.
  • The text already gives the true cause. The PM accepted 404. The TL rated it low.

Decision: keep 404.
